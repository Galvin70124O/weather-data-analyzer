# Weather icons

Animated "Meteocons" by Bas Milius (https://github.com/basmilius/weather-icons), MIT License (see LICENSE).
These are the `production/fill/openweathermap` files from `@bybas/weather-icons@2.0.0`, named after
OpenWeatherMap's icon codes (`01d` = clear day, `10n` = rain at night, ...).
